# Cloudscape 3D 项目定位与方案

> 状态：方向已初步确定，首批客群与产品形态待最终拍板
> 更新日期：2026-10-01
> 来源：由「老家电博物馆 Demo」升级为「基于 COSMO Code 的 3D 解决方案」

## 1. 项目概述

Cloudscape 3D 是基于 COSMO Code 构建的一站式 3D 展示解决方案。项目起点是老家电博物馆 Demo，它验证了 3D 展厅在停留时长与观感上的价值。下一阶段从单个展馆升级为可复制、可交付的产品能力。

一句话定位：让企业像发一条内容一样，搭建可交互、可分享、可交易的沉浸式 3D 空间。

## 2. 项目名

- 英文名：Cloudscape 3D
- 中文名：云境（建议，待确认）
- 定位语：基于 COSMO Code 的 3D 解决方案

## 3. 方向定位

候选方向

| 代号 | 方向 | 说明 |
|------|------|------|
| A | 3D 商品云展厅 | 品牌线上展厅 + 3D 商品展示 + 电商导购 |
| B | 工业 3D 数字孪生展示 | 设备 / 产线 3D 展示与运维 |
| C | 3D 内容生产工具链 | AI 生成 glb / 建模，让企业自助生产 3D 内容 |
| D | 3D 数字博物馆 / 文化展馆 | 面向文博文旅的垂直展馆 |

推荐路线：以 A 为主体，C 作为底层能力贯穿，B 与 D 作为行业化扩展方向。技术底座统一，行业差异体现在模板与组件层。

## 4. 目标客户

- 家电 / 家居 / 汽车 / 文旅 / 工业制造品牌
- 政府 / 园区 / 展会主办方
- 博物馆 / 科技馆 / 纪念馆

首批客群建议：海尔与卡奥斯生态内品牌，便于快速拿到样板与真实数据（待确认）。

## 5. 核心价值

- 替代或补充线下展厅，实现 7x24 在线展示
- 3D 商品展示提升转化率与用户停留
- AI 降低 3D 内容的生产成本与交付周期

## 6. 架构分层

1. 内容生产层：AI 建模（文 / 图生 3D）、GLB 导入、模型优化管线（Draco / Meshopt / KTX2）
2. 场景编排层：展厅模板、拖拽布展、灯光材质预设、导览动线
3. 交互体验层：Three.js / R3F 渲染、热点、参数卡、导购、VR 模式
4. 发布分发层：链接 / 二维码 / 官网嵌入 / 大屏、多端自适应
5. 数据运营层：埋点、热力、转化看板

## 7. 技术选型

- 渲染：Three.js + React Three Fiber（生态成熟），重性能场景可切 Babylon.js
- 状态与 UI：React + Tailwind
- 模型管线：gltf-transform 做压缩与格式转换
- AI 建模：接入 3D 生成模型 API（Hunyuan3D / Tripo / Meshy 等）
- 存储与分发：对象存储 + CDN
- 后端：Node (NestJS) 或 Go
- 部署：COSMO Code 一键部署

## 8. 商业模式

- SaaS 订阅：按展厅数 / 存储 / 流量计费
- 项目制定制：大型展馆整体交付
- 增值服务：AI 建模按次计费、行业模板商城

产品形态建议：SaaS 自助平台为主，标杆项目定制并行（待确认）。

## 9. 发展规划

- P0 样板验证（2-3 周）：以老家电博物馆为主体，接入 1-2 个真实客户试用，验证停留时长与咨询转化
- P1 MVP（1-2 月）：模板展厅 + 模型上传 + 一键发布 + 基础埋点
- P2 平台化（2-3 月）：账号体系、多展厅管理、AI 建模、导购组件、官网嵌入、数据看板
- P3 生态化（6 月以上）：行业模板市场、设备与产线数字孪生接入、交易闭环、私有化部署

## 附：现有 Demo 资产
